# Отчёт о функциональном паритете `aibrofist` → `testaibrofist`

## Итог проверки

Клиентская игровая логика, редактор и основные страницы `testaibrofist` сохранены совместимыми с оригиналом. В тестовой версии добавлен локальный runtime: по умолчанию страницы работают через `file://` без Express, Socket.IO и внешнего API. Серверный режим оригинала сохраняется и включается явно параметром `online=1` на игровой странице.

## Что теперь работает локально

| Функция оригинала | Локальная реализация |
|---|---|
| Race | Один игрок, локальный счёт, финиш, смена карт, Practice/God/Fly |
| Hide and Seek | Один игрок + локальный бот, рулетка выбора, переход lobby → round, роль искателя/прячущегося и таймеры |
| Каталог карт | Локальные карты в `localStorage`, фильтры, сортировка, избранное, рейтинг |
| Редактор и публикация | `/uploadMap` заменён локальным сохранением карты с тем же форматом `mapData` |
| Просмотр карты | `?view=...` загружает выбранную карту из локального каталога |
| Story Mode | Локальное создание комнаты/кода, сохранение метаданных и запуск выбранной карты |
| Комнаты | Локальный список с одной комнатой и одним игроком |
| Профиль | Локальный пользователь `Local Tester`, монеты, очки, настройки и статистические ответы |
| Leaderboard | Локальная строка результата текущего игрока |
| Quests | Локальный endpoint-контракт для отображения/claim без сервера |
| Daily Reward | Локальное колесо награды и начисление монет |
| Чат и рисование | Сохраняются в игровом клиенте; локальный transport обрабатывает эхо и квоту |
| Телепорт | Локальная карта использует корректную пару `targetIds`/`customId`, как требует движок |
| Admin Abuse | Не показывается в offline runtime и не загружается на игровой странице |

## Точные точки входа

```text
file:///.../testaibrofist/race.html
file:///.../testaibrofist/hide-and-seek.html
file:///.../testaibrofist/mapsBrowser.html
file:///.../testaibrofist/story.html
file:///.../testaibrofist/editor.html
file:///.../testaibrofist/daily.html
```

Игровой режим:

```text
file:///.../testaibrofist/game.html?mode=race
file:///.../testaibrofist/game.html?mode=hideAndSeek
file:///.../testaibrofist/game.html?mode=hideAndSeek&role=seeker
```

Для возврата к серверному пути оригинала:

```text
file:///.../testaibrofist/game.html?mode=race&online=1
```

## Ограничение, связанное с single-player

Функции, которые по смыслу требуют второго реального сетевого игрока, не могут быть буквально сетевым мультиплеером при условии «без серверов». Поэтому в локальном варианте они представлены тестовыми эквивалентами: локальным ботом, одним локальным участником, локальным состоянием комнаты и теми же событиями/UI-фазами. Оригинальная серверная синхронизация, античит и межустройственная игра не изменены и остаются доступны только при `online=1`.
