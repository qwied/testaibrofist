# AIBROFIST v103 — плавность, безопасность, новые иконки

## 1. ГЛАВНОЕ — плавность движения (то, что ты просил)

Чужие игроки теперь едут по экрану **так же плавно, как твой собственный**:

| Что изменилось | Было | Стало |
|---|---|---|
| Кадры сервера (снапшоты) | 20 в секунду | **30 в секунду** |
| Отправка твоего движения | 20 в секунду | **30 в секунду** |
| Минимальная задержка чужих | 45 мс | **32 мс** |
| Камера | догоняла игрока плавно (отставала!) | **прилипла намертво** — ноль отставания экрана |
| Опорный кадр (лечение потерь) | раз в 2 секунды | **раз в секунду** |
| Экстраполяция при потере пакета | до 100 мс | **до 120 мс** |
| FPS на слабых телефонах | как повезёт | **адаптивное разрешение**: если кадр дороже 30 мс, холст снижает разрешение на шаг — FPS держится за 30; когда устройство тянет, качество возвращается само |
| Задержка TCP (Nagle) | включена | **выключена (TCP_NODELAY)** — пакеты уходят мгновенно |

Плюс: фон карты больше не пересоздаётся 60 раз в секунду (мелкий, но бесплатный прирост FPS).

**Важно про пинг 30–40 мс для всех:** код ускорил всё, что мог. Оставшиеся миллисекунды — это РАССТОЯНИЕ до сервера. Игроки рядом с сервером получат 10–40 мс, игроки с другого континента — как есть физика. Хочешь низкий пинг по всему миру — Cloudflare Workers за $5/мес (обсуждали раньше).

## 2. Безопасность — что закрыто

- **Удалён мёртвый и опасный код** `saveMap`/`getMaps` (сокеты): через них любой игрок мог забить до 400 МБ памяти сервера и уронить его. Ни одна страница игры их не использовала — удалено полностью.
- **Чужие сайты больше не могут открывать сокеты** к игре (allowRequest: источник должен совпадать с хостом сайта). Раньше сторонний сайт мог гонять сокеты от имени твоих игроков.
- **История чата** отдаётся только своей комнаты (раньше можно было подглядывать чужие).
- **Удаление картинок скинов**: путь файла теперь жёстко проверяется регуляркой перед удалением с диска.
- **Чистка памяти шоу монет**: счётчики пойманных монет больше не копятся бесконечно.
- Мелкое: `mode` в /getBestRoom чистится как имя комнаты.

Всё проверено тестами и живой атакой в E2E: чужой Origin получает отказ, свой — работает.

## 3. Новые иконки Race и HideAndSeek

- **Race**: та же сцена (бегуны в гору к финишному флагу), но теперь закат — тёплое небо, солнце, облачка другой формы, барьер другой конструкции.
- **Прятки**: та же сцена (куст, прячущийся, искатель с «?»), но небо голубое с облаками, куст двухцветный, добавлен второй маленький куст.

Файлы те же (`mode-race.png`, `mode-hide.png`), кэш сброшен версией `?v=103`.

## 4. Как выложить

1. (Если мигрируешь на другой хостинг) На старом сервере: панель владельца → Резервная копия → Скачать.
2. Задеплой v103 (как обычно: Railway → Deploy from GitHub или загрузка).
3. Если переезжал: панель владельца → Резервная копия → Восстановить (файл из шага 1).
4. Cloudflare не трогаем — ничего не слетит.
