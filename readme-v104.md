# AIBROFIST v104 — возврат иконок, английская база, честный пинг

## 1. Иконки Race и Пряток — вернулись прежние

В v103 я перерисовал иконки страниц режимов, и получилось расхождение: на главной
карточки показывали СТАРЫЕ иконки, а на страницах Race/Пряток — новые. Причина:
на главной иконки были зашиты прямо в HTML (base64), а на страницах режимов —
отдельными файлами mode-race.png / mode-hide.png. Обновил я только файлы.

Теперь везде снова **оригинальные иконки** (из твоего исходника, байт в байт):

- `mode-race.png` и `mode-hide.png` восстановлены из v100 (проверено размерами: 30497 и 4100 байт);
- карточки на главной больше не хранят копии-баз64, а ссылаются на те же файлы
  (`mode-hide.png?v=104`, `mode-race.png?v=104`) — рассинхрон больше невозможен в принципе;
- кэш обойдён версионным параметром `?v=104`.

## 2. Заголовки страниц — по-английски и без дублей

Ты правильно заметил «AiBrofist - AiBrofist - Map Editor»: в `game.html` в заголовке
имя сайта было продублировано. Исправлено, заодно вся «информация о ссылках»
(то, что видно во вкладке браузера и в превью ссылки в Telegram/WhatsApp) — английская:

| Страница | Было | Стало |
|---|---|---|
| Редактор (game.html) | AIBrofist — AIBrofist — Editor | **AIBrofist — Map Editor** |
| Редактор (editor.html) | AIBrofist — Editor | **AIBrofist — Map Editor** |
| Прятки | AIBrofist — Прятки | **AIBrofist — Hide and Seek** |
| Гонка | AIBrofist — Гонка | **AIBrofist — Race** |
| Темы | AIBrofist — Темы | **AIBrofist — Themes** |
| Профиль | AIBrofist — Профиль | **AIBrofist — Profile** |
| Главная | AIBrofist | AIBrofist (без изменений) |

То же самое сделано для описаний ссылок (meta description + og:title/og:description
всех страниц) — теперь они на английском, как и описание режимов.

## 3. Основной язык сайта — английский

- Базовый язык сайта теперь **английский**: заголовки, ссылки, описания, подписи.
- Автоперевод «по стране игрока» (у русских автоматически включался русский) **отключён**.
- Язык меняется только вручную: **Menu → Settings → Language** — выбор сохраняется
  в браузер и в аккаунт, все 10 языков на месте (ru, en, uk, de, fr, es, pt, pl, tr, zh).
- Атрибут `lang="en"` выставлен на всех страницах.

## 4. Про пинг 150 мс — честно

В твоём видео пинг гуляет 115–170 мс. Это НЕ код — код уже отправляет пакеты без
задержек (TCP_NODELAY, websocket-first, 30 Гц). Миллисекунды — это **расстояние
до сервера Railway**. Два рабочих решения:

1. **Быстро (10 минут, бесплатно):** Railway → твой сервис → Settings → Region →
   изменить на **Frankfurt (eu-central)** → Redeploy. Для игроков из СНГ это
   обычно 30–60 мс вместо 150.
2. **Глобально:** проект `aibrofist-worker` (Cloudflare Workers + Durable Objects),
   я собирал его отдельно — с тест-страницей для замера пинга.

Пока сервер стоит не там — никакая версия кода пинг не снизит.
