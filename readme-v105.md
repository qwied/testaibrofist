# AIBROFIST v105 — пинг 30–60 мс без смены сервера и без скачиваний

## Что это за версия

Ты просил: пинг 30–40 мс, НЕ переезжая на Frankfurt и ничего не скачивая.
Физику обмануть нельзя: пока пакеты ходят до далёкого дата-центра, у цифры
на экране есть нижний предел — расстояние. Поэтому v105 делает две вещи:

1. **Добавляет в игру быстрый сервер на Cloudflare Workers** (бесплатный тариф
   Cloudflare, у тебя аккаунт уже есть). Он принимает подключения в 300+
   городах у самого игрока — реальный пинг 10–60 мс. Railway остаётся КАК ЕСТЬ:
   на нём работают аккаунты, карты, монеты. Ничего не переезжает, ничего
   не скачивается и не устанавливается — деплой одной командой через `curl`
   (он уже встроен в Windows 10/11 и macOS).
2. **Делает игру быстрой даже на старом сервере**: если воркер не подключён
   или недоступен, игра автоматически играет через Railway, как раньше.

Полная инструкция по деплою — в папке `aibrofist-worker` (файл `README-RU.md`),
коротко — ниже.

## Подключить быстрый сервер (10 минут)

1. **Токен:** dash.cloudflare.com → My Profile → API Tokens → Create Token →
   шаблон **Edit Cloudflare Workers** → Create → скопировать.
2. **Account ID:** dash.cloudflare.com → Workers & Pages → справа → скопировать.
3. **Деплой:** в папке `aibrofist-worker` запусти `deploy.bat` (Windows) или
   `sh deploy.sh` (macOS/Linux), вставь две строки. Жди `"success": true`.
4. **Проверка пинга:** открой `https://aibrofist-ws.САБДОМЕН.workers.dev` —
   тест-страница покажет твой реальный пинг до нового сервера.
5. **Включить в игру:** в `game.js` в самом верху впиши адрес:
   ```js
   var DEFAULT_WS_URL = 'wss://aibrofist-ws.САБДОМЕН.workers.dev/ws';
   ```
   (рекомендуется маршрут на своём домене: `wss://твой-домен.com/ws` —
   шаг 6 в README воркера, адрес `*.workers.dev` местами блокируется).
6. Замени файлы на Railway и перезапусти. Готово — смотр пинг в углу экрана.

**Безопасность:** воркер не примет подключения с чужих сайтов (ALLOWED_ORIGIN),
а если воркер упадёт или кончится дневной лимит — игра сама за ~6 секунд
вернётся на Railway. Ничего не ломается ни у кого.

## Что изменено в коде

- `game.js`:
  - `makeSocket` — шим socket.io поверх чистого WebSocket (Workers не умеет
    socket.io): `.on/.emit/.id/.connected`, connect/disconnect, автопереподключение;
  - `DEFAULT_WS_URL` + параметр `?ws=` — быстрый сервер включается одной строкой
    или ссылкой, без него поведение ровно прежнее;
  - авто-возврат на старый сервер после трёх неудачных попыток (мёртвый воркер,
    лимит Free, блокировка провайдера);
  - темп отправки движения: 30 Гц на старом сервере, 20 Гц через воркер
    (каждое сообщение воркера считается запросом — бережём дневной лимит),
    1 пакет/с когда ты один в комнате;
  - при входе новичка каждый игрок переотправляет скин/размер/цвет — чужие
    скины у новичка появляются мгновенно (и на воркере, и на старом сервере);
  - таймеры пинга больше не дублируются при переподключении.
- `worker.js` (новый файл в aibrofist-worker): полный игровой сервер на
  Durable Objects — комнаты, движение, скины, чат, пинг, **фазы пряток
  с рулеткой** (живут даже после засыпания DO — их будит alarm), лимитеры
  флуда, чистка имён, защита от чужих Origin. Протокол 1:1 с server.js.

## Лимиты бесплатного тарифа (честно)

Каждое входящее сообщение движения = 1 запрос к Durable Object.

| Тариф | Лимит | На что хватает |
|---|---|---|
| Free | ~100 000/день | ≈ 1 час суммарной игры в день |
| Paid $5/мес | ~10 000 000/мес | ≈ 4–6 часов суммарной игры в день |

Стоящие на месте игроки почти не тратят лимит. Когда он кончается — игра
автоматически возвращается на Railway до сброса в 00:00 UTC.
