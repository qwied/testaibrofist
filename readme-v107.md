## 3. Свой образ сохраняется в «Мои скины»

Новая кнопка **«Сохранить в «Мои скины»»** на странице Avatar: спрашивает
название (2–30 символов) и кладёт собранный образ в личную коллекцию, после
чего сразу открывает вкладку «Мои скины».

Новый маршрут `POST /skins/save`:
- только для вошедших в аккаунт;
- в образ попадают **только бесплатные и уже купленные вещи** — если в наборе
  есть неоплаченная деталь, сохранение отклоняется;
- не даёт сохранить два образа с одним названием и два одинаковых набора;
- до **20 образов** на аккаунт, счётчик свободных мест виден под кнопкой
  (`GET /skins/limit`).

Личные образы помечаются флагом `personal: true` и не попадают:
- в `GET /skins/list` и `GET /getSkins` / `GET /getSkinsForList` (общий обзор);
- в витрину Avatar — владелец не может выставить чужой личный образ на продажу;
- в чужой профиль: `GET /userSkins?name=…` отдаёт их только самому автору.

Оценивать личные образы нельзя, рейтинг у них не показывается. Кнопки «Надеть»
и «Удалить» работают как раньше.
