# v77 — вода прежнего дизайна: тело-лужа + капли, без canvas-фильтров

## Проблема v76
«Шарики»: рендер осевших частиц опирался на canvas-фильтр (goo:
feGaussianBlur + порог альфы). В Safari/iOS canvas-фильтров нет —
срабатывал запасной путь «мягкой линзы», и каждая частица рисовалась
отдельным мягким пятном. Даже в Chrome метабол-круги давали бугристую
кромку из «шариков» на тонких слоях воды.

## Решение (editor.html + game.html, зеркально)
Полностью переписан модуль «РЕНДЕР ЖИДКОСТИ» — без canvas-фильтров,
чистыми путями, одинаковый вид во всех браузерах:

1. **Колонки и стопки.** Осевшие частицы ложатся в колонки по 6px
   (LIQ_COLW); внутри колонки частицы сортируются по y и режутся на
   связные стопки (разрыв больше 9px — новая стопка). Редкий капёж и
   брызги стопками не становятся.
2. **Дорожки-тела.** Тело — только ОПЁРТАЯ вода: низ стопки стоит на
   твёрдом (liqSolidAt) либо это плёнка до 13px (проверенный критерий
   старой поверхности). Быстрые стопки (|v| > 2.5) телом не бывают —
   падающая струя и спрей рисуются каплями. Разрыв колонки, вторая
   стопка в той же колонке или скачок верха больше 14px рвут тело.
3. **Один контур на группу.** Верх дорожки — волна liqWob (та же, что
   у прямоугольных бассейнов), дно — по нижним частицам, бока с
   запасом полколонки. Эллипсы капель струи дописываются в тот же
   контур; заливка одним градиентом за один проход — без швов и без
   двойной прозрачности.
4. **Градиент прежнего бассейна** (те же цвета и альфы 0.36/0.44/0.6),
   интерполирован по высоте самого тела.
5. **Капли — два прохода** (liqDrops):
   - струя из курсора (pourParts с радиусом) — плотная лента 0.55;
   - брызги-частицы в воздухе — маленькие круглые точки 2.2px с
     непрозрачностью 0.32 и только при локальной плотности (в клетке
     8px есть ещё капля): одиночек не видно — так старый goo-порог
     прятал соло-брызги. Иначе тысяча разлетевшихся брызг сливалась
     в мутное облако на весь экран.
6. **Пена и пузыри** (liqSurface) идут по готовым дорожкам тела
   (g._runs) — светлая полоса и кромка лежат ровно на нарисованном
   верхе; у падающей воды (быстрые колонки) пены нет.

## Что не менялось
Физика частиц (SPH-давление, растекание, выравнивание, капание,
плавание, впитывание бассейнами, save/load, undo/redo) — без
изменений: вода так же разливается, как в v75/v76.
