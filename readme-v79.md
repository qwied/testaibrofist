# AIBROFIST v79 — вода «в точности как на видео» и ровное растекание

## Что просил пользователь
«Вот такая вода нужна в точности, но чтобы разливалась равномерно как вода»
(видео: авторский бассейн — чистое тело, волнистая поверхность, светлая
полоса, пена, пузыри). Прошлые версии рисовали налитую воду «гусеницей из
капсул» (v78) и «шариками» (v75–v77) — вид не совпадал с авторским.

## Что сделано (editor.html + game.html, движок зеркален)
Полностью переписан рендер налитой жидкости — модуль «РЕНДЕР ЖИДКОСТИ»:
- Осевшая вода собирается в БАССЕЙНЫ авторского вида: колонки 6px ->
  вертикальные отрезки частиц -> у каждого отрезка своя опора
  (три точки под дном: слой «парит» над опорой на 1–7px) или сосед-
  бассейн; соседние осевшие отрезки со схожим верхом (≤14px) срастаются
  в дорожку-бассейн.
- Бассейн рисуется ОДНИМ контуром «волнистый верх — ровное дно по опоре —
  вертикальные бока» и красится тем же градиентом (0.36/0.44/0.6), полосой
  света, пеной на гребне и пузырями, что и прямоугольная вода, — один в один.
- У одной колонки может быть ДВА бассейна на разных уровнях (плёнка на
  полке + лужа на земле под ней) — расслоение по отрезкам, а не по колонкам.
- Высокий одинокий отрезок (всплеск/струя над поверхностью) бассейном не
  становится — «шпиль» в точке удара струи исчез.
- Вода в полёте (струя из курсора, водопад, брызги) — капсулы пути,
  сшитые в сплошную ленту (капля дотягивается до ближайшей ниже);
  тихая пыль над бассейном — мягкие капли, без бугров на кромке.
- Без canvas-фильтров — одинаково в Chrome и Safari.

Физика v75 (SPH-давление, растекание, выравнивание, капание с уступов,
плавание, кислота) не тронута — изменилась только картинка.
