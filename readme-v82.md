# v82 — Skin Editor: рисование, PLAY внутри Maps Browser, рейтинг и переводы

## 1. Skin Editor полностью переделан — теперь это рисование

- **Готовые модельки убраны.** Каталога деталей (кепки, очки, плащи) в редакторе больше нет — вместо него холст рисования.
- **Игрок рисует скин сам** прямо по фигуре: кисть, ластик, 14 цветов палитры + свой цвет, 4 толщины кисти, отмена (до 25 шагов), очистка зоны и очистка всего.
- **Редактирование по частям тела:** клик рядом с головой — редактируется только голова, клик по туловищу — только туловище. Первый клик по другой зоне только выбирает её (без случайной точки). Активная зона подсвечена пунктиром, продублирована кнопками Head/Body.
- **Сохранение:** рисунок экспортируется в PNG (силуэт + оба слоя) и надевается на игрока — новый эндпоинт `POST /skin/drawing` (требует входа). Скин хранится как картинка и виден в игре у всех (тот же механизм, что у скинов-картинок владельца).
- **Публикация в Skins Browser:** рисунком тоже можно делиться. Дубликаты ловятся по md5-отпечатку картинки, лимит 5 в сутки и награда в монетах — как раньше.
- Надетый готовый скин-картинка (например, загруженный владельцем) показывается в редакторе картинкой с кнопкой «Рисовать», чтобы случайно не затереть.

## 2. PLAY в Maps Browser больше не меняет ссылку

- Раньше кнопка PLAY уводила на `game.html` — адрес в браузере менялся.
- Теперь карта открывается в модальном окне прямо поверх Maps Browser: страница и адрес остаются на месте. В шапке окна — название карты и автор, есть кнопка «Закрыть» (работает и Escape, и клик по фону). При закрытии игра в кадре останавливается.

## 3. Удалённые режимы убраны из Maps Browser

- Из фильтра режимов исчезли Two Player Adventure и Sandbox — остались только Прятки и Гонка.
- То же исправлено в панели владельца (кнопки «Добавить в игру» больше не показывают мёртвые режимы — раньше сервер их отклонял).

## 4. Единый рейтинг везде

- В Maps Browser и Skins Browser вместо двух чисел (лайки/дизлайки) теперь **одно число: лайки минус дизлайки**.
- Цвет: больше нуля — зелёный, меньше нуля — красный, ноль — нейтральный. Без знаков «+» и «-».
- То же в профиле игрока (вкладка Skins).
- Кнопки 👍/👎 с текущими счётчиками остались — это форма голосования.

## Технические детали

- `skinEditor.html` — переписан: холст 200×672 (2× плотность), слои зон с клиппингом, undo-стек, экспорт PNG.
- `userSkins.js` — `POST /skin/drawing` (сохранить рисунок), `/skins/publish` принимает `img` (dataURL или ссылку), twin-проверка по md5.
- `mapsBrowser.html` — модальное окно проигрывания, фильтр без удалённых режимов, рейтинг одним числом.
- `skinsBrowser.html`, `users.html` — рейтинг одним числом с цветом.
- `game.js` + `i18n.js` — переводы игрового экрана, новые ключи на 10 языках.
- `owner.js` — список режимов синхронизирован с сервером (hideAndSeek, race).
