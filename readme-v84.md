# v84 — Skin Editor: прежний редактор + 90 аксессуаров

## Skin Editor возвращён к классическому виду

- **Редактор снова с готовыми модельками** — рисование по частям тела из v82 убрано, страница `skinEditor.html` вернулась к прежнему виду: фигура игрока + слоты Head / Face / Body / Back + карточки предметов.
- **Кнопки «Случайный образ» (Randomise) больше нет** — образ собирается только вручную.
- Подзаголовок редактора снова «Все детали бесплатны…» на всех 10 языках.

## Каталог вырос с 34 до 90 аксессуаров

Все предметы бесплатны, перекраска игрока не тронута (цвет по-прежнему задаёт игра — роль в прятках).

## Технические детали

- `skins.js` — CATALOG расширен до 94 позиций (86 аксессуаров + 4 слота «Ничего»); API (`/skin/catalog`, `/skin/equip`, `/skin/save`, нормализация, подпись дубликатов) не менялся — новые предметы сразу работают и на сервере.
- `skinRender.js` — у каждого нового предмета своя отрисовка (SVG + те же фигуры для canvas, так что в игре персонаж выглядит как в редакторе). Починен конструктор круга: теперь кольца с обводкой рисуются (у «Номера» кольцо вокруг круга не отображалось).
- «Спинные» предметы посажены так, чтобы красиво выглядывать из-за силуэта: скейтборд с колёсами по диагонали, стрелы колчана над плечом, шар и рукоять меча справа.
- `skinEditor.html` — прежняя версия из v83 без кнопки Randomise; мост для панели владельца (загрузка скина-картинки) сохранён.
- `i18n.js` — восстановлен прежний текст `skinSub`.
- `POST /skin/drawing` из v82 оставлен в `userSkins.js` — не мешает, скины-картинки владельца по-прежнему работают.

- Все 9 наборов тестов игры зелёные; `node --check` всех правленых файлов.
