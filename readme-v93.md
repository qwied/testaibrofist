# v93 — нормальная сила прыжка и платформа, которая толкает, а не швыряет

## Сила прыжка

Дело было не в физике столкновений, а в короткой кнопке. Подъём длится больше
двадцати кадров, а касание JUMP на телефоне — три-пять. Срез высоты при раннем
отпускании (`vy += G*0.68`) включался с первого же кадра, поэтому тап давал
**80 px** вместо 116. Ряды полок на картах стоят в 83–104 px друг от друга — до
соседнего ряда игрок просто не долетал, сколько ни жми.

Два изменения:

- `JUMP_H` 122 → **168**;
- первые `MIN_HOLD = 7` кадров подъём не режется вообще, а дальше срез мягче
  (`0.68` → `0.5`).

| | было (тап / зажато) | стало (тап / зажато) |
|---|---|---|
| лёгкая гравитация | 79 / 117 px | **130 / 162 px** |
| обычная | 80 / 116 px | **133 / 161 px** |
| тяжёлая | 81 / 115 px | **136 / 160 px** |

Разница между тапом и зажатой кнопкой осталась (28 px) — низкий прыжок никуда
не делся, просто он больше не вдвое ниже обычного.

## Платформа толкает, но не телепортирует

В v91 толчок был обрезан до 3 px и платформа топила игрока в себе; в v92 быстрая
платформа проходила сквозь. Теперь одно правило на оба случая:

```js
var right = outR < outL;                 // куда ближе выйти
var move  = Math.min(PUSH_MAX, need);    // PUSH_MAX = 12 px за кадр
pl.x += right ? move : -move;
```

Платформа всегда двигает игрока **в ближнюю сторону** и не быстрее 12 px за кадр.

- Обычная платформа везёт игрока перед собой, как стенка.
- Слишком быстрая продавливается сквозь: игрок оказывается ближе к задней грани
  и выходит назад — плавно, по 12 px за кадр.
- Выброса на противоположный край не бывает никогда. Это и был телепорт.

Рывок при проезде платформы сквозь стоящего игрока (ход 1600, скорость 6):
**58 px за кадр в v88 → 12 px сейчас.**

## Что не изменилось

- Приземление по-прежнему решается тем, откуда игрок пришёл (v92), поэтому
  стоять и ездить на платформе можно при любой её скорости: 100 % кадров,
  зазор 0 px.
- Столкновения со статичной геометрией не тронуты: прогон 2640 сценариев прыжка
  на полку даёт 0 расхождений с прежней логикой.

Версии статики подняты до `?v=93`.
