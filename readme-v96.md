# v96 — угол отталкивает вбок, а не телепортирует наверх

## Что не так в v95

Платформа прижимала игрока к стене — и его выбрасывало **на верх соседнего
объекта**. Игрок стоял на углу платформы, рядом была стена, платформа шла
дальше — и вместо того чтобы оттолкнуть игрока вбок, физика ставила его
на верх стены. В любую сторону, в любом месте — телепорт.

## Где жила дыра

В вертикальном проходе коллизий была ветка «иначе» для неподвижных блоков:

```js
} else if(!o.moves){
  // глубокий провал в неподвижный блок — как раньше, ставим сверху
  pl.y = sp[0] - pl.h; pl.ground = true; coy = COYOTE; pl.vy = 0; pl.selfJump = false;
}
```

Она срабатывала, когда игрок оказывался **сбоку** от блока (не сверху, не
снизу) — то есть на угле. И всегда ставила его на верх. Горизонтальный
проход такого игрока не выталкивал: страховка из v95 пропускала случай,
когда вбок пришлось бы двигаться дальше `|vx| + 8` — и отдавала его
вертикальному проходу. А тот — на верх.

## Как сделано теперь

В той же ветке проверяем, насколько игрок зашел в блок сбоку. Если
ближайшая боковая грань близко (≤ 32 px) — это угол, отталкиваем вбок
к ней. Если обе грани далеко (игрока продавили в середину широкого
блока) — по-прежнему ставим наверх: из широкого блока вбок это швыряло
бы на всю его длину, и v95 именно так и делало (2419 px).

```js
var spX = spanX(P, pl.y + 2, pl.y + pl.h - 2);
var lPen = spX ? (pl.x + pl.w) - spX[0] : 1e9;
var rPen = spX ? spX[1] - pl.x : 1e9;
if(Math.min(lPen, rPen) <= 32){
  if(lPen <= rPen){ pl.x = spX[0] - pl.w; if(pl.vx > 0) pl.vx = 0; pl.wall = 1; }
  else            { pl.x = spX[1];        if(pl.vx < 0) pl.vx = 0; pl.wall = -1; }
} else {
  pl.y = sp[0] - pl.h; pl.ground = true; coy = COYOTE; pl.vy = 0; pl.selfJump = false;
}
```

- работает **в каждую сторону**: левый угол толкает влево, правый — вправо;
- работает **в каждом месте**: проверка идёт по ближней грани многоугольника,
  так что и прямоугольник, и круг, и треугольник, и повёрнутый блок — все
  отталкивают от настоящей грани;
- прыжок не тронут: `pl.ground`, `coy`, `pl.vy`, `pl.selfJump` на угле
  не выставляются, потому что игрок в воздухе, а не на земле. Ветка прыжка
  (строки с `keys.u` и `jumpV()`) не менялась.

## Замеры

Поведенческие тесты в `test-ui.js` гоняют настоящий шаг физики:

| сценарий | v95 | v96 |
|---|---|---|
| игрок на углу стены (15 px внутри) | teleports to y=40 | **отталкивает вбок, y=200** |
| угол с правой стороны | teleports to y=40 | **отталкивает вправо** |
| глубокий провал в середине пола (600 px) | поднимает наверх | **поднимает наверх** (без изменений) |
| приземление на платформу сверху | садится | **сидит** (без изменений) |
| прыжок с тапа / удержания | 133 / 161 px | **133 / 161 px** (без изменений) |

Физика: 24 проверки пройдены, 0 ошибок. Без фикса — 4 падения именно
на углах. Все 8 тестовых файлов зелёные.

## Что не изменилось

- Прыжок: `JUMP_H = 168`, `MIN_HOLD = 7`, тап 133 px, зажатая кнопка 161 px.
- Статичная геометрия: приземление на полку, удар головой, скольжение
  по стене — всё как в v95.
- Толчок платформой: сторона по «откуда пришёл», потолок в темпе платформы.
- Глубокий провал в широкий блок: поднимает наверх (регресс на v95).

Версии статики подняты до `?v=96`.
