# v97 — картинки в новостях

Владелец кидает в Logs любые изображения, игроки видят их без битой
вёрстки и без битых значков.

## Как это работает

**Владелец.** В редакторе новости появилась панель: кнопка «Добавить
изображения», перетаскивание файлов и вставка из буфера (Ctrl+V) —
до 8 картинок на новость. Каждая показывается миниатюрой с размером
в килобайтах и крестиком «убрать». Рядом с «Удалить» у каждой новости
теперь есть «Изменить»: текст и набор картинок правятся без потери даты.

**Игроки.** Одна картинка идёт во всю ширину (высота ограничена 520 px),
несколько — плиткой. Клик открывает во весь экран, Esc и клик по фону
закрывают. Гости видят всё то же самое.

## Что сделано против багов

| что ломалось бы | как закрыто |
|---|---|
| прыжок вёрстки, пока картинка грузится | при загрузке снимаются ширина и высота, в ленте стоит `aspect-ratio` — место занято заранее |
| фото с телефона на 8 МБ | браузер сам ужимает до 1600 px и webp/JPEG 0.86 до отправки; гифки и SVG не трогаем, чтобы не убить анимацию и вектор |
| прозрачный PNG чернеет при пережатии | если webp не поддерживается, под JPEG подкладывается белый фон |
| файл не открылся (удалили, сеть) | вместо битого значка ровная плашка «Изображение недоступно», соседи не съезжают |
| чужой адрес в поле картинки | сервер принимает только свои `/logimg/…`, проверяет имя по маске и наличие файла на диске |
| подсунули не картинку | тип определяется по байтам файла (PNG, JPEG, GIF, WebP, BMP, AVIF, SVG), а не по расширению |
| SVG со скриптом внутри | раздаётся в песочнице: `default-src 'none'; sandbox` + `nosniff`, как скины |
| мусор на диске | файлы удалённой новости стираются; загруженное, но не опубликованное — через 2 часа; общая картинка двух новостей не удаляется вместе с одной из них |
| тяжёлое тело запроса | лимит 20 МБ поднят **только** для `/log/upload`, остальные маршруты остались на 512 КБ |
| лента обновилась и стёрла черновик | автообновление раз в минуту пропускается, пока владелец пишет или грузит |

Попутно закрыт старый баг: номер новости был `Date.now()`, и две записи,
созданные в одну миллисекунду, получали одинаковый номер — «Удалить»
могло стереть не ту. Теперь номер всегда больше предыдущего.

## Файлы

- `extras.js` — `/log/upload`, картинки в `/addLog`, новый `/editLog`,
  уборка файлов, уникальные номера.
- `server.js` — раздача `/logimg` с песочницей и годовым кэшем,
  лимит тела для загрузки.
- `logs.html` — панель картинок, галерея, просмотр во весь экран,
  цвета через переменные темы (в тёмной теме заголовки больше не тонут).
- `test-logs.js` — новый файл, 52 проверки.

## Замеры

`test-logs.js`: 52 проверки, 0 ошибок — права, подделка типа, лимит
12 МБ, лимит 8 картинок, чужие адреса, выход из папки, правка,
удаление файлов с диска, разметка страницы. Остальные 8 тестовых
файлов зелёные, физика — 24 проверки без ошибок.

## Хранение

Картинки лежат в `data/logimg` рядом с `logs.json`. Если на Railway этот
каталог не на постоянном томе, после передеплоя пропадут и новости, и
картинки — лента тогда покажет плашку «Изображение недоступно» вместо
битых значков.

Версии статики подняты до `?v=97`.
